# Android 위치 기록 실습

로그인과 위치 기록 기능을 한 앱에 연결해 본 Android 실습 프로젝트임.

- 기간: 2025.05.20 ~ 2025.06.03
- 구분: Android 수업 실습
- 기술: Java, Android, Google Play Services

## 연습한 내용

- 회원가입과 로그인 정보를 `SharedPreferences`에 저장했음.
- 화면 이동과 웹, 전화, 지도, 연락처 열기를 연결했음.
- 간단한 메모 화면을 추가했음.
- 포그라운드 서비스로 위치를 계속 확인하게 했음.
- 기준 위치와의 거리, 머문 시간을 사용자별로 저장했음.

## 현재 상태

- 여러 Android 기본 기능을 합쳐 본 학습용 앱임.
- 실제 서비스 배포를 위한 앱은 아님.

## 실행 방법

- Android Studio에서 열고 위치 권한을 허용한 기기에서 실행하면 됨.
